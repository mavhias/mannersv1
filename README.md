# BeManners – Application Meteor

Ce projet est une version mise à jour et modernisée de l'application BeManners, fonctionnant avec Meteor 3.2+ et Node.js 20. Il a été migré depuis une ancienne version de Meteor, avec suppression complète de la dépendance à `fibers` et remplacement par des appels `async/await`.

## Pré-requis

- [Node.js 20.x LTS](https://nodejs.org/en/download/releases)
- [Meteor 3.2+](https://docs.meteor.com/)
- [nvm (facultatif mais recommandé)](https://github.com/nvm-sh/nvm)
